# Generate a vector of school assignments for all individuals in the population

School sizes are sampled with replacement from a reference dataset. This
is known as bootstrapping. The dataset used is
[`schools_usa`](https://mrc-ide.github.io/helios/reference/schools_usa.md).

## Usage

``` r
generate_initial_schools(parameters_list, initial_age_classes)
```

## Arguments

- parameters_list:

  A list of model parameters as generated by `get_parameters`

- initial_age_classes:

  A character vector assigning an age class to each individual
