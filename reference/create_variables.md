# Generate a list of the model variables

Generate a list of the model variables

## Usage

``` r
create_variables(parameters_list, population_data)
```

## Arguments

- parameters_list:

  A list of model parameters as generated by `get_parameters`

- population_data:

  The population data, as generated by
  [`generate_population_data()`](https://mrc-ide.github.io/helios/reference/generate_population_data.md)
