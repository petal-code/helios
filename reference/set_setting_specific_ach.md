# Set ACH distribution for a setting type

Activates setting-specific ACH for a single setting and configures the
truncated-normal distribution from which each location's baseline ACH is
drawn. Per-location ACH values feed into both the riskiness calculation
(via
[`convert_ach_to_riskiness()`](https://mrc-ide.github.io/helios/reference/convert_ach_to_riskiness.md))
and any intervention efficacy calculation (via
[`calculate_efficacy_from_ach()`](https://mrc-ide.github.io/helios/reference/calculate_efficacy_from_ach.md)).

## Usage

``` r
set_setting_specific_ach(parameters_list, setting, mean, sd)
```

## Arguments

- parameters_list:

  A list of model parameters as generated by
  [`get_parameters()`](https://mrc-ide.github.io/helios/reference/get_parameters.md).

- setting:

  Character. One of `"workplace"`, `"school"`, `"leisure"`, or
  `"household"`.

- mean:

  Mean of the truncated normal ACH distribution (1/hour).

- sd:

  Standard deviation of the truncated normal ACH distribution (1/hour).

## Value

The input `parameters_list` with the setting's switch turned on and the
mean/sd populated.
