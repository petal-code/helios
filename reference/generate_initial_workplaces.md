# Gets workplace assignments for all individuals in the population

Gets workplace assignments for all individuals in the population

## Usage

``` r
generate_initial_workplaces(
  parameters_list,
  initial_age_classes,
  initial_school_settings
)
```

## Arguments

- parameters_list:

  A list of model parameters as generated by `get_parameters`

- initial_age_classes:

  A character vector assigning an age class to each individual

- initial_school_settings:

  An integer vector assigning individuals to schools
