# Run the simulation

Run the simulation

## Usage

``` r
run_simulation(parameters_list, state = NULL)
```

## Arguments

- parameters_list:

  A list of model parameters as generated by
  [`get_parameters()`](https://mrc-ide.github.io/helios/reference/get_parameters.md)

- state:

  Optional simulation state from a previous run, as returned in the
  `state` element of the output list. When provided, the simulation
  resumes from this state. `simulation_time` controls the number of
  *additional* timesteps to run (not the absolute end time). With
  time-varying transmission, beta vectors are indexed by day from the
  start of the original run, so they must have a value for every day up
  to the end of the resumed run. The population is rebuilt from the seed
  saved in the state, so `parameters_list$seed` must be `NULL` or that
  same seed, and the population parameters must not change. The random
  number streams continue from the state, so a run resumed from a state
  matches an uninterrupted run. Default is `NULL` (start fresh).

## Value

A list with two elements:

- result:

  A data frame of simulation outputs with one row per timestep simulated
  in this call. When resuming, `timestep` counts from the start of the
  original run, so the results of successive calls can be joined with
  [`rbind()`](https://rdrr.io/r/base/cbind.html). The columns are
  described below.

- state:

  The final simulation state, which can be passed to a subsequent call
  to resume the simulation. A list with elements `timesteps` (the number
  of timesteps simulated so far), `individual` (the state of the
  individual package's variables, events and base R's random number
  generator), `dqrng` (dqrng's random number state) and `seed` (the seed
  that built the population, drawn at random when `parameters_list$seed`
  is `NULL`).

The `result` data frame always contains the following columns:

- `timestep`: The simulation timestep index.

- `S_count`: The number of individuals in the Susceptible disease state.

- `E_count`: The number of individuals in the Exposed (infected but not
  yet infectious) disease state.

- `I_count`: The number of individuals in the Infectious disease state.

- `I_mild_count`: The number of individuals in the mild Infectious
  disease state.

- `I_hosp_count`: The number of individuals in the severe Infectious
  disease state that require hospitalization.

- `R_count`: The number of individuals in the Recovered (immune) disease
  state.

- `D_count`: The number of individuals in the Death state.

- `E_new`: The number of individuals newly transitioning from
  Susceptible to Exposed (i.e. new infections) at each timestep.

When `endemic_or_epidemic = "endemic"`, an additional column is
included:

- `n_external_infections`: The number of susceptible individuals
  infected via the external/background infection source at each
  timestep.

When `render_diagnostics = TRUE`, additional diagnostic columns are
included:

- `FOI_household`: The maximum force of infection from household
  contacts across all individuals at each timestep.

- `FOI_workplace`: The maximum force of infection from workplace
  contacts across all individuals at each timestep.

- `FOI_school`: The maximum force of infection from school contacts
  across all individuals at each timestep.

- `FOI_leisure`: The maximum force of infection from leisure setting
  contacts across all individuals at each timestep.

- `FOI_community`: The community-level force of infection (derived from
  global prevalence) at each timestep.

- `FOI_total`: The maximum total force of infection (sum across all
  settings) experienced by any individual at each timestep.
