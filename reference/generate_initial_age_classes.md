# Generates a vector of the age classes of all individuals in the population

Generates a vector of the age classes of all individuals in the
population

## Usage

``` r
generate_initial_age_classes(parameters_list)
```

## Arguments

- parameters_list:

  A list of model parameters as generated by `get_parameters`
