# Set a uniform default ACH for a setting type

Configures a single setting so that every location in it has the same
baseline ACH. This is the "uniform" alternative to
[`set_setting_specific_ach()`](https://mrc-ide.github.io/helios/reference/set_setting_specific_ach.md),
which draws per-location ACH values from a distribution.

Sets the package parameter `default_ach_<setting>` to `ach`. Because the
setting-specific switch stays FALSE, the model treats this setting as
"no per-location variation" — every location in the setting gets ACH
equal to `ach`.

Each setting already has a uniform default ACH set by
[`get_parameters()`](https://mrc-ide.github.io/helios/reference/get_parameters.md),
so this function is only needed to override that default.

## Usage

``` r
set_default_ach(parameters_list, setting, ach)
```

## Arguments

- parameters_list:

  A list of model parameters as generated by
  [`get_parameters()`](https://mrc-ide.github.io/helios/reference/get_parameters.md).

- setting:

  Character. One of `"workplace"`, `"school"`, `"leisure"`, or
  `"household"`.

- ach:

  Numeric. The uniform ACH value assigned to every location in the
  setting (1/hour). Must be non-negative.

## Value

The input `parameters_list` with `default_ach_<setting>` set to `ach`.
