# Generate a list of leisure settings that each individual visits

Each element of this list indicates which settings each individual
visits on which day. The value 0 indicates that the person stays in on
that day.

## Usage

``` r
generate_initial_leisure(parameters_list, leisure_setting_sizes)
```

## Arguments

- parameters_list:

  A list of model parameters as generated by `get_parameters`

- leisure_setting_sizes:

  The sizes of the leisure settings as sampled using
  [`sample_negbinom()`](https://mrc-ide.github.io/helios/reference/sample_negbinom.md)
