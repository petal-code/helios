# Create process governing exposed to infectious disease state transition

Performs an age-dependent binomial split of newly transitioning exposed
individuals between I_mild and I_hosp. Counts `H_new` at entry to
I_hosp.

## Usage

``` r
create_EI_process(variables_list, events_list, parameters_list, renderer)
```

## Arguments

- variables_list:

  A list of model variables as generated by
  [`create_variables()`](https://mrc-ide.github.io/helios/reference/create_variables.md)

- events_list:

  A list of the model events as generated by
  [`create_events()`](https://mrc-ide.github.io/helios/reference/create_events.md)

- parameters_list:

  A list of model parameters as generated by
  [`get_parameters()`](https://mrc-ide.github.io/helios/reference/get_parameters.md)

- renderer:

  An individual-package render object
