# Generates a vector of households for all individuals in the population

Alternative to
[`generate_initial_households()`](https://mrc-ide.github.io/helios/reference/generate_initial_households.md).
Rather than using a parametric distribution, this function uses sampling
with replacement from a reference dataset. This is known as
bootstrapping. The dataset used is
[`baseline_household_demographics_uk`](https://mrc-ide.github.io/helios/reference/baseline_household_demographics_uk.md)
or
[`baseline_household_demographics_usa`](https://mrc-ide.github.io/helios/reference/baseline_household_demographics_usa.md).
Unlike
[`generate_initial_households()`](https://mrc-ide.github.io/helios/reference/generate_initial_households.md),
this function generates both the household and age class assignments
together.

## Usage

``` r
generate_initial_households_bootstrap(parameters_list)
```

## Arguments

- parameters_list:

  A list of model parameters as generated by `get_parameters`
