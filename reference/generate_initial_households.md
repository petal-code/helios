# Generates a vector of households for all individuals in the population

Generates a vector of households for all individuals in the population

## Usage

``` r
generate_initial_households(parameters_list, age_class_variable)
```

## Arguments

- parameters_list:

  A list of model parameters as generated by `get_parameters`

- age_class_variable:

  An
  [`individual::CategoricalVariable`](https://mrc-ide.github.io/individual/reference/CategoricalVariable.html)
  for the age classes
