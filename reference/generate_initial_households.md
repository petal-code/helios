# Generates a vector of households for all individuals in the population

Households are sampled with replacement from a reference dataset. This
is known as bootstrapping. The dataset used is
[`baseline_household_demographics_usa`](https://mrc-ide.github.io/helios/reference/baseline_household_demographics_usa.md).
This function generates both the household and age class assignments
together.

## Usage

``` r
generate_initial_households(parameters_list)
```

## Arguments

- parameters_list:

  A list of model parameters as generated by `get_parameters`
