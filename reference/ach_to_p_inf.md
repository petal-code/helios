# Wells-Riley infection probability per location

Computes the absolute (unnormalised) single-exposure Wells-Riley
infection probability for each location in a setting:

\$\$p\_{inf}(i) = 1 - \exp(-r \cdot C\_{ss}(i) \cdot RR\_{tv} \cdot
t)\$\$ \$\$C\_{ss}(i) = (I \cdot \pi) / (\alpha_i \cdot V), \quad
\alpha_i = ACH_i + k_D\$\$

Unlike
[`convert_ach_to_riskiness()`](https://mrc-ide.github.io/helios/reference/convert_ach_to_riskiness.md),
the returned values are not normalised against a within-setting
reference, so they are directly comparable across setting types. This is
required when pooling locations from different settings for joint
intervention targeting, where a within-setting normalisation would make
equal values from different settings represent unequal absolute risk.

## Usage

``` r
ach_to_p_inf(ach_values, parameters_list, setting)
```

## Arguments

- ach_values:

  Numeric vector of per-location baseline ACH values (1/hour), as
  returned by
  [`generate_setting_specific_ach()`](https://mrc-ide.github.io/helios/reference/generate_setting_specific_ach.md).

- parameters_list:

  A list of model parameters as generated by
  [`get_parameters()`](https://mrc-ide.github.io/helios/reference/get_parameters.md).
  The Wells-Riley parameters and the setting volume
  (`volume_per_person_<setting>`) are read from here.

- setting:

  Character. One of `"workplace"`, `"school"`, `"leisure"`, or
  `"household"`. Used to select the appropriate `volume_per_person_*`.

## Value

Numeric vector of per-location infection probabilities, same length as
`ach_values`.
