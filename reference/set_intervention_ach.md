# Install an intervention into the parameters list

Stores a single intervention object (as produced by
[`make_intervention()`](https://mrc-ide.github.io/helios/reference/make_intervention.md))
into the parameters list under the chosen `setting`. The intervention is
not yet allocated to specific locations — that happens later via
[`generate_intervention_data()`](https://mrc-ide.github.io/helios/reference/generate_intervention_data.md)
when
[`run_simulation()`](https://mrc-ide.github.io/helios/reference/run_simulation.md)
runs.

Setting "joint" pools workplace + school + leisure into a single
coverage budget; household is intentionally excluded from joint
deployment. The four per-setting options ("workplace", "school",
"leisure", "household") install the intervention independently into one
setting. A joint intervention cannot be combined with setting-type
specific interventions.

Currently single-intervention only — passing more than one intervention
will error. Multi-intervention support lives on a separate branch.

## Usage

``` r
set_intervention_ach(
  parameters_list,
  setting,
  coverage_target,
  coverage_type,
  timestep,
  intervention
)
```

## Arguments

- parameters_list:

  A list of model parameters as generated by
  [`get_parameters()`](https://mrc-ide.github.io/helios/reference/get_parameters.md).

- setting:

  Character. One of `"workplace"`, `"school"`, `"leisure"`,
  `"household"`, or `"joint"`.

- coverage_target:

  Character. What the coverage fraction applies to — either
  `"individuals"` (count of people) or `"square_footage"`
  (size-weighted, using `size_per_individual_<setting>`).

- coverage_type:

  Character. How locations are selected for coverage — either `"random"`
  (uniform sampling until the coverage budget is met) or
  `"targeted_riskiness"` (locations ranked in decreasing order of
  riskiness).

- timestep:

  Numeric. First simulation timestep at which the intervention's
  efficacy is applied in the FOI calculation.

- intervention:

  One intervention object as returned by
  [`make_intervention()`](https://mrc-ide.github.io/helios/reference/make_intervention.md).

## Value

The input `parameters_list` with the `intervention_<setting>_*` slots
populated. For `setting = "joint"`, the `intervention_joint_coverage`
slot is additionally populated from the intervention object's `coverage`
field.
