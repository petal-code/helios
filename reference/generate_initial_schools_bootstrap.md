# Generate a vector of school assignments for all individuals in the population

Alternative to `generate_initial_schools`. Rather than using a
parametric distribution, this function uses sampling with replacement
from a reference dataset. This is known as bootstrapping. The dataset
used is
[`schools_uk`](https://mrc-ide.github.io/helios/reference/schools_uk.md).

## Usage

``` r
generate_initial_schools_bootstrap(parameters_list, age_class_variable)
```

## Arguments

- parameters_list:

  A list of model parameters as generated by `get_parameters`

- age_class_variable:

  An
  [`individual::CategoricalVariable`](https://mrc-ide.github.io/individual/reference/CategoricalVariable.html)
  for the age classes
