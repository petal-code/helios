# Compute per-location intervention efficacy from baseline ACH

Applies the Wells-Riley framework to compute per-location efficacy for
an installed intervention. For each covered location `i`:

\$\$efficacy_i = 1 - p\_{post}(i) / p\_{pre}(i)\$\$

where `p_pre` and `p_post` are the Wells-Riley infection probabilities
before and after the intervention's delta-eACH is added to that
location's baseline ACH. Uncovered locations get `delta = 0`, which
gives `efficacy = 0` and so leave FOI unchanged downstream.

The intervention's delta per location is determined by the intervention
object's `delta_function` (and `delta_params`, `variation`,
`variation_params`); see
[`make_intervention()`](https://mrc-ide.github.io/helios/reference/make_intervention.md).

Called once at simulation init from
[`create_variables()`](https://mrc-ide.github.io/helios/reference/create_variables.md).

## Usage

``` r
calculate_efficacy_from_ach(ach_values, parameters_list, setting)
```

## Arguments

- ach_values:

  Numeric vector of baseline ACH values per location in the setting.

- parameters_list:

  A list of model parameters as generated by
  [`get_parameters()`](https://mrc-ide.github.io/helios/reference/get_parameters.md)
  (and populated by
  [`set_intervention_ach()`](https://mrc-ide.github.io/helios/reference/set_intervention_ach.md)
  and
  [`generate_intervention_switches()`](https://mrc-ide.github.io/helios/reference/generate_intervention_switches.md)).

- setting:

  Character. One of `"workplace"`, `"school"`, `"leisure"`, or
  `"household"`.

## Value

Numeric vector of per-location efficacies, length equal to
`length(ach_values)`. Each value is in `[0, 1]`; uncovered locations
return 0.
