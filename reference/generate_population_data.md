# Generate a population for the given parameters

This will sample individuals' initial state and assign them to
households and other locations. It also draws the baseline ACH and
riskiness of each location. Interventions are not part of the
population: see
[`generate_intervention_data()`](https://mrc-ide.github.io/helios/reference/generate_intervention_data.md).

## Usage

``` r
generate_population_data(parameters_list)
```

## Arguments

- parameters_list:

  A list of model parameters as generated by `get_parameters`

## Value

A named list describing the population. Its `seed` element is the seed
the population was built with: `parameters_list$seed`, or a seed drawn
at random when that is `NULL`. With it,
[`run_simulation()`](https://mrc-ide.github.io/helios/reference/run_simulation.md)
can rebuild the population when a saved run is resumed. Its `rng_state`
element is the state of the random number generators after the
population was drawn, so that
[`generate_intervention_data()`](https://mrc-ide.github.io/helios/reference/generate_intervention_data.md)
can continue the same random stream. Its `parameters` element holds the
values of the parameters the population was built from. The list has
class `helios_population`.

A population can be reused, eg. with different interventions or seeds,
but only with parameters that have the same values for all the
parameters it was built from. These include the population size, the
initial disease states, the setting sizes, the ACH settings, the volumes
per person and the Wells-Riley parameters, but not the seed.
[`generate_intervention_data()`](https://mrc-ide.github.io/helios/reference/generate_intervention_data.md)
and
[`run_simulation()`](https://mrc-ide.github.io/helios/reference/run_simulation.md)
error otherwise.
