# Generate the intervention data for a population

Determines which locations have an intervention deployed, and the
resulting per-location efficacy for each setting with an active
intervention. This is kept separate from
[`generate_population_data()`](https://mrc-ide.github.io/helios/reference/generate_population_data.md)
so that the same population can be reused with different interventions.

It seeds the random number generators itself, so its result does not
depend on earlier random draws, and it is the intervention data that
[`run_simulation()`](https://mrc-ide.github.io/helios/reference/run_simulation.md)
uses. When `parameters_list$seed` is the seed the population was built
with, it continues the population's random stream, as if the population
and the intervention were drawn in one go. Otherwise it starts a new
stream from `parameters_list$seed`.

It errors if `population_data` was built from different values of the
population parameters than `parameters_list` (see
[`generate_population_data()`](https://mrc-ide.github.io/helios/reference/generate_population_data.md)).

## Usage

``` r
generate_intervention_data(parameters_list, population_data)
```

## Arguments

- parameters_list:

  A list of model parameters as generated using
  [`get_parameters()`](https://mrc-ide.github.io/helios/reference/get_parameters.md)

- population_data:

  A list representing the population, containing at least the
  `setting_sizes`, `<setting>_specific_ach` and
  `<setting>_specific_riskiness` entries, as generated by
  [`generate_population_data()`](https://mrc-ide.github.io/helios/reference/generate_population_data.md)

## Value

A list with three elements:

- switches:

  The coverage switches, as returned by
  [`generate_intervention_switches()`](https://mrc-ide.github.io/helios/reference/generate_intervention_switches.md).

- efficacy:

  A named list containing, for each setting with an active intervention,
  the per-location efficacy as returned by
  [`calculate_efficacy_from_ach()`](https://mrc-ide.github.io/helios/reference/calculate_efficacy_from_ach.md).

- timestep:

  A named list containing, for each setting with an active intervention,
  its `intervention_<setting>_timestep`: efficacy is applied at the
  timesteps after it.

A joint intervention counts as active in the workplace, school and
leisure settings, with the joint intervention list and timestep.
