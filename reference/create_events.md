# Generate a list of model events with listeners

Listeners are arbitrary functions called when the event is fired. Their
only argument is the current time step.

## Usage

``` r
create_events(variables_list, parameters_list)
```

## Arguments

- variables_list:

  A list of the model variables as generated by
  [`create_variables()`](https://mrc-ide.github.io/helios/reference/create_variables.md)

- parameters_list:

  A list of model parameters as generated by
  [`get_parameters()`](https://mrc-ide.github.io/helios/reference/get_parameters.md)
