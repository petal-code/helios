# Create process governing recovered (and immune) back to susceptible disease state transition

Create process governing recovered (and immune) back to susceptible
disease state transition

## Usage

``` r
create_RS_process(variables_list, events_list, parameters_list)
```

## Arguments

- variables_list:

  A list of model variables as generated by
  [`create_variables()`](https://mrc-ide.github.io/helios/reference/create_variables.md)

- events_list:

  A list of the model events as generated by
  [`create_events()`](https://mrc-ide.github.io/helios/reference/create_events.md)

- parameters_list:

  A list of model parameters as generated by
  [`get_parameters()`](https://mrc-ide.github.io/helios/reference/get_parameters.md)
