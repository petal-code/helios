# Convert per-location ACH values to per-location riskiness

Applies the Wells-Riley framework to convert each location's baseline
ACH into a relative riskiness value (a per-location multiplier on the
FOI).

For each location `i`: \$\$p\_{inf}(i) = 1 - \exp(-r \cdot C\_{ss}(i)
\cdot RR\_{tv} \cdot t)\$\$ \$\$C\_{ss}(i) = (I \cdot \pi) / (\alpha_i
\cdot V), \quad \alpha_i = ACH_i + k_D\$\$

Riskiness is then normalised so that the mean across locations is
exactly 1: \$\$riskiness_i = p\_{inf}(i) / \overline{p\_{inf}}\$\$ where
\\\overline{p\_{inf}}\\ is the mean of \\p\_{inf}\\ over all locations
in the setting.

Because the Wells-Riley exponent is small for our parameter values,
`1 - exp(-x) \approx x`, and riskiness simplifies to approximately
`(1 / (ACH_i + kD)) / mean(1 / (ACH_j + kD))`, i.e. it depends only on
ACH. The constants `I`, `pi`, `RR_tv`, `t`, and `V` cancel.

Called once per setting by
[`generate_population_data()`](https://mrc-ide.github.io/helios/reference/generate_population_data.md),
immediately after
[`generate_setting_specific_ach()`](https://mrc-ide.github.io/helios/reference/generate_setting_specific_ach.md).
The result is stored at `<setting>_specific_riskiness` in the population
data and used by `processes.R` to scale the per-setting FOI.

## Usage

``` r
convert_ach_to_riskiness(ach_values, parameters_list, setting)
```

## Arguments

- ach_values:

  Numeric vector of per-location baseline ACH values (1/hour), as
  returned by
  [`generate_setting_specific_ach()`](https://mrc-ide.github.io/helios/reference/generate_setting_specific_ach.md).

- parameters_list:

  A list of model parameters as generated by
  [`get_parameters()`](https://mrc-ide.github.io/helios/reference/get_parameters.md).
  The Wells-Riley parameters (`wells_riley_emission_rate`,
  `wells_riley_decay_rate`, `wells_riley_infection_prob_per_ffu`,
  `wells_riley_respiratory_rate_factor`, `wells_riley_time_in_room`) and
  the setting volume (`volume_per_person_<setting>`) are read from here.

- setting:

  Character. One of `"workplace"`, `"school"`, `"leisure"`, or
  `"household"`. Used to select the appropriate `volume_per_person_*`.

## Value

Numeric vector of per-location riskiness values, same length as
`ach_values`, anchored so mean riskiness across locations is exactly 1.
